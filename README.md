# Parcial Final - Spec Driven Development

## Nombre del proyecto

Calculadora de Nota Final Universitaria

## Descripción

Este proyecto consiste en una aplicación web sencilla que permite calcular cuánto necesita sacar un estudiante en la última nota de una materia para aprobar con mínimo 3.0.

El desarrollo se realizó siguiendo el enfoque de Spec Driven Development, donde primero se definieron los requerimientos y reglas del sistema antes de generar el código.

## IA utilizada

ChatGPT

## Archivos del proyecto

- SPEC.md: contiene la especificación del sistema.
- PROMPT.md: contiene el prompt utilizado con la IA.
- index.html: contiene la aplicación desarrollada.
- ANALISIS.md: contiene el análisis del resultado.

## Requerimientos principales

- Ingresar nombre de la materia.
- Ingresar notas obtenidas.
- Ingresar porcentajes de cada nota.
- Calcular nota acumulada.
- Calcular nota necesaria para aprobar.
- Validar notas entre 0.0 y 5.0.
- Validar que los porcentajes no superen el 100%.
- Mostrar mensajes claros al usuario.

## Cómo ejecutar el proyecto

1. Descargar el repositorio.
2. Abrir el archivo index.html en un navegador.
3. Ingresar las notas y porcentajes.
4. Presionar el botón calcular.

## Análisis general

La solución cumple con la especificación definida inicialmente. La aplicación es funcional, sencilla y permite validar diferentes escenarios de cálculo. Como mejora futura, se podría guardar el historial de materias o exportar los resultados.
